# 巨哼的五重身份 - H5 Galgame Demo v3 北京版

## 运行方式

推荐进入目录后运行：

```bash
python3 -m http.server 5173
```

然后打开：

```txt
http://localhost:5173
```

## v3 更新

- 剧情从 `index.html` 拆出到 `data/story.js`
- 三条路线：Lolita线、职业装线、护士线
- 每条路线都比上一版明显加长
- 增加跨路线记忆：
  - 完成 Lolita Good 后，职业装线会出现隐藏选项
  - 完成任意 Good 后，序章会出现交叉线入口
  - 完成 2 个 Good 后，可进入 True Ending 预告
- 保留 BGM、打字机、选项动效、立绘淡入、本地存档、结局收集

## 后续建议

如果要做到真正 10-20 分钟/路线，可以继续把每条路线扩到：
- 每章 15-25 个节点
- 每条路线 70-100 个节点
- 每个 Good/Normal/Bad 结局再扩 3-5 个节点

当前 v3 已经把架构改好，后面主要就是往 `data/story.js` 追加剧情。


## v3 北京版更新

已将游戏里的虚构城市和地点替换成北京语境：

- 明月市 → 北京
- 车站出口 → 北京南站出口
- 复古茶室 → 五道营胡同复古茶室
- 云阶大厦 → 国贸写字楼 / 国贸 CBD
- 市立医院 → 北京协和医院
- 河岸步道 → 亮马河步道
- 医院附近公园 → 朝阳公园
- 旧书店 → 鼓楼旧书店

后续还可以继续细化具体场景，比如：
- Lolita线：五道营胡同 / 雍和宫附近 / 鼓楼
- 职业装线：国贸 CBD / 望京 / 中关村
- 护士线：协和 / 北医三院 / 朝阳医院
- True线：亮马河 / 什刹海 / 奥森烟火夜景


## v3 preload 更新

新增资源加载页：

- 进入游戏时先预加载所有立绘图片
- 进入游戏时先预加载所有 BGM 音频
- 显示加载进度条和百分比
- 资源加载完成后才显示开始菜单
- 音乐仍需要用户点击按钮后才能播放，这是手机浏览器/微信 H5 限制

如果 GitHub Pages 访问慢，首次加载可能仍然慢，但不会出现“首页出来了图片和音乐还没准备好”的割裂体验。
